# Sample data notes

For a public repository, do **not** upload real BOM, EAS exports, purchase orders, inventory files, supplier information, prices, or production orders.

Recommended approach:

1. Create a few anonymized BOM workbooks using fake material codes and fake quantities.
2. Create anonymized EAS-like inventory / PO / purchase-application workbooks containing only the columns needed by the program.
3. Remove supplier names, prices, purchase order numbers, customer names, employee names, internal paths, and other company identifiers.
4. Put the anonymized examples in this folder only after internal approval.
